# Sarinda Restaurant — UI/UX Specification
## Design Concept 2: Fresh & Vibrant

### UX Principle
Every screen should answer one question quickly: “What should I do next?” The main actions are Order, View Menu, Book a Table, and Contact.

### Navigation
Desktop:
Home | Menu | Offers | Gallery | About | Contact | Search | Order Now

Mobile:
Logo | Menu icon
Sticky bottom actions:
Menu | Cart | Order

### Screen 01 — Homepage
Sections:
- Hero with Order Now + Book a Table
- Trust indicators
- Popular Menu horizontal cards
- Signature dish
- Current offers
- Restaurant story
- Reviews
- Gallery
- Reservation CTA
- Map/contact
- Footer

### Screen 02 — Menu
Top:
- Search
- Category tabs
- Optional dietary/filter controls

Categories:
Biryani, Chicken, Mutton, Fish & Prawn, Set Menu, Dessert, Drinks.

Item card:
Image → Name → Short description → Price → Add

### Screen 03 — Product Detail
- Large food image
- Name
- Price
- Description
- Quantity
- Add to Cart
- Recommended add-ons

Upsell example:
“Complete your meal”
+ Borhani
+ Chicken Fry
+ Dessert

### Screen 04 — Cart
- Selected items
- Quantity controls
- Remove
- Suggested add-ons
- Subtotal
- Delivery/service charge
- Total
- Checkout

### Screen 05 — Checkout
Fields:
Name, Phone, Delivery Address, Notes.
Payment options should be configurable.
Primary CTA: Place Order.

### Screen 06 — Reservation
Fields:
Date, Time, Guests, Name, Phone, Special Request.
Confirmation state should clearly show the request status.

### Screen 07 — Offers
Each campaign gets:
- Hero image
- Offer title
- Validity
- Terms
- Order CTA

### Screen 08 — AI Assistant
Chat UI should be simple and human.
Suggested prompts:
- “Show today's popular dishes”
- “What can I order for 4 people?”
- “Book a table”
- “Where are you located?”

AI must never invent price, availability or reservation confirmation.

### Screen 09 — Admin Dashboard
Cards:
Orders Today | Revenue | Reservations | New Customers
Charts:
Orders over time, top dishes, campaign conversions.
Tables:
Recent orders and reservations.

### Conversion UX
Primary CTA = Order Now.
Secondary CTA = Book a Table.
Every marketing landing page should have one dominant conversion goal.

### Accessibility
- Keyboard navigable
- Visible focus state
- Adequate contrast
- Large touch targets
- Alt text for meaningful images
- Error messages next to fields
